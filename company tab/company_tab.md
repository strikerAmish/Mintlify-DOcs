## About us: Giving AI a persistent mind.

Most AI applications bolt on basic retrieval (RAG) and call it memory. But retrieval only finds documents. True memory understands a person, tracks a project, and updates its worldview as facts change. That architectural difference is what we are building.

We build PiyAPI, the memory infrastructure for human-like AI. It gives agents the ability to remember, learn from experience, and build a continuous understanding of the world around them.

### Retrieval (RAG) vs. Memory (PiyAPI)

| FEATURE | RETRIEVAL (RAG) | MEMORY (PIYAPI) |
| :--- | :--- | :--- |
| **What it keeps** | Document chunks | Facts about each user, over time |
| **When facts change** | Old and new chunks both come back | Contradictions are resolved |
| **Time** | No sense of when | Knows when a fact was true and when it was learned |
| **Forgetting** | Keeps everything forever | Expired information is actively forgotten |

## Our vision & mission

**Vision: Continuity for AI**
In a world of complex data, we provide the clarity that reveals true potential. We believe the next step for AI is continuity: agents that know who they work with, notice when facts change, and get better with every conversation instead of starting over.

**Mission: Build the memory layer for human-like AI, and keep it accurate, open, and private.**

* **Remember like people do**: Memory should know when something was true, notice when it stops being true, and let go of what no longer matters.
* **Memory you own**: The same API runs in our cloud or as a single binary on your own machine, fully offline if you need it to be.
* **Private by default**: PII and PHI redaction, namespace isolation, and data residency are part of the core, not an add-on.
