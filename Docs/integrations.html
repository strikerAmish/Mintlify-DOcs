Integrations / Agent Frameworks / LangChain

LangChain Integration

Official LangChain adapter (packages/langchain-adapter) providing persistent bitemporal memory retrieval and context injection for LangChain chains and agents.

Installation

pip install packages/langchain-adapter
# Or install client memory library
pip install piyapi-memory

Code Example (from User Guide §5.3)

from piyapi_langchain import PiyAPIMemoryRetriever

# Initialize memory retriever with API key and namespace scope
retriever = PiyAPIMemoryRetriever(
    api_key="sk_live_your_key_here",
    user_id="dev_lead",
    scope="project"
)

# Retrieve relevant context documents directly for LangChain chains and agents
docs = retriever.get_relevant_documents("user database preferences")
for doc in docs:
    print(doc.page_content)
Supported Capabilities: Bitemporal validity filtering (valid_at), 11-signal UnifiedScorer reranking, and scoped namespace isolation across user sessions.
Integrations / Agent Frameworks / LangGraph

LangGraph Integration

Connect cyclic state machines and multi-actor graphs with bitemporal memory and checkpoint persistence.

Installation

pip install langgraph langchain-openai piyapi-memory

StateGraph Memory Node Example

from typing import TypedDict, List
from langgraph.graph import StateGraph, END
from piyapi import PiyAPIClient

# Initialize PiyAPI client
piyapi = PiyAPIClient(api_key="sk_live_your_key_here")

class AgentState(TypedDict):
    messages: List[dict]
    user_id: str
    retrieved_context: str

def recall_memory_node(state: AgentState):
    # Query bitemporal memory using UnifiedScorer (11 signals)
    query = state["messages"][-1]["content"]
    results = piyapi.memories.search(
        query=query,
        user_id=state["user_id"],
        limit=5
    )
    context = "\n".join([r["content"] for r in results])
    return {"retrieved_context": context}

# Construct LangGraph workflow
workflow = StateGraph(AgentState)
workflow.add_node("recall", recall_memory_node)
workflow.set_entry_point("recall")
workflow.add_edge("recall", END)
app = workflow.compile()
Key Advantages: Cyclic graphs retain user preferences, historical constraints, and decision logs across infinite conversational turns without bloating the active prompt window.
Integrations / Agent Frameworks / LlamaIndex

LlamaIndex Integration

Connect PiyAPI hybrid vector retrieval and knowledge graph indices directly into LlamaIndex query engines.

Installation

pip install llama-index piyapi-memory

Hybrid Retriever Setup

from llama_index.core.retrievers import BaseRetriever
from llama_index.core.schema import NodeWithScore, TextNode
from piyapi import PiyAPIClient

class PiyAPILlamaRetriever(BaseRetriever):
    def __init__(self, api_key: str, user_id: str):
        self.client = PiyAPIClient(api_key=api_key)
        self.user_id = user_id
        super().__init__()

    def _retrieve(self, query_bundle):
        memories = self.client.memories.search(
            query=query_bundle.query_str,
            user_id=self.user_id,
            limit=5
        )
        return [
            NodeWithScore(
                node=TextNode(text=m["content"]),
                score=m.get("score", 1.0)
            ) for m in memories
        ]

CrewAI Integration

Provide multi-agent crews with a unified shared context graph (PiyGraph) and tool-level memory synchronization.

Installation

pip install crewai piyapi-memory

Shared Context Tool Example (User Guide §7.3)

from crewai import Agent, Crew, Task
from crewai.tools import tool
from piyapi import PiyAPIClient

client = PiyAPIClient(api_key="sk_live_your_key_here")

@tool("Query Shared Team Knowledge")
def search_team_memory(query: str) -> str:
    # Searches the shared PiyGraph knowledge graph for historical architectural facts
    res = client.memories.search(query=query, scope="project", limit=3)
    return "\n".join([m["content"] for m in res])

researcher = Agent(
    role='Senior Systems Architect',
    goal='Design resilient microservices adhering to recorded enterprise guidelines',
    tools=[search_team_memory],
    verbose=True
)
Integrations / Agent Frameworks / AutoGen

AutoGen Integration

Retain cross-turn conversational state, mined facts, and user preferences in Microsoft AutoGen multi-agent swarms.

Installation

pip install autogen-agentchat piyapi-memory

ConversableAgent Memory Hook

from autogen import ConversableAgent
from piyapi import PiyAPIClient

piyapi = PiyAPIClient(api_key="sk_live_your_key_here")

def sync_turn_to_memory(recipient, messages, sender, config):
    # Automatically extract facts and persist to PiyAPI bitemporal storage
    if messages:
        last_msg = messages[-1]["content"]
        piyapi.memories.create(
            content=last_msg,
            user_id="autogen_session_01",
            tags=["autogen", "session-turn"]
        )
    return False, None

agent = ConversableAgent(
    name="AssistantWithMemory",
    llm_config={"model": "gpt-4o"}
)
agent.register_hook(hookable_method="process_message_before_send", hook=sync_turn_to_memory)

Integrations / AI SDKs / Vercel AI SDK

Vercel AI SDK Integration

Stream generative responses while capturing and recalling user memory in real-time Next.js and Node.js applications.

Installation

npm install ai @ai-sdk/openai @piyapi/sdk

Next.js Route Handler with Auto-Persistence

import { streamText } from 'ai';
import { openai } from '@ai-sdk/openai';
import { PiyAPIClient } from '@piyapi/sdk';

const piyapi = new PiyAPIClient({ apiKey: process.env.PIYAPI_API_KEY });

export async function POST(req: Request) {
  const { messages, userId } = await req.json();
  const lastMessage = messages[messages.length - 1].content;

  // 1. Retrieve persistent user context
  const memories = await piyapi.memories.search({ query: lastMessage, userId, limit: 3 });
  const systemContext = memories.map(m => m.content).join('\n');

  // 2. Stream response with context
  return streamText({
    model: openai('gpt-4o'),
    system: `User Profile Context:\n${systemContext}`,
    messages,
    onFinish: async ({ text }) => {
      // Auto-extract and persist learnings
      await piyapi.memories.create({ content: `Q: ${lastMessage} | A: ${text}`, userId });
    }
  }).toDataStreamResponse();
}

LiveKit Integration

Real-time speech-to-speech agent memory synchronization with sub-100ms context injection for conversational voice.

Installation

pip install livekit-agents livekit-plugins-openai piyapi-memory

Voice Agent Lifecycle Example

from livekit.agents import JobContext, WorkerOptions, cli
from livekit.agents.voice_assistant import VoiceAssistant
from piyapi import PiyAPIClient

piyapi = PiyAPIClient(api_key="sk_live_your_key_here")

async def entrypoint(ctx: JobContext):
    await ctx.connect()
    participant = await ctx.wait_for_participant()

    # Pre-warm context by retrieving participant history
    mems = piyapi.memories.search(query="preferences", user_id=participant.identity)
    summary = " ".join([m["content"] for m in mems])

    assistant = VoiceAssistant(
        instructions=f"You are a friendly voice assistant. User knowledge: {summary}"
    )
    assistant.start(ctx.room, participant)
Integrations / Voice & Real-Time / Pipecat

Pipecat Integration

Add low-latency contextual recall into Pipecat multimodal voice, audio, and video pipelines.

Installation

pip install pipecat-ai piyapi-memory

Pipeline Frame Processor

from pipecat.processors.frame_processor import FrameProcessor
from pipecat.frames.frames import TranscriptionFrame
from piyapi import PiyAPIClient

class PiyAPIMemorySync(FrameProcessor):
    def __init__(self, api_key: str, user_id: str):
        super().__init__()
        self.client = PiyAPIClient(api_key=api_key)
        self.user_id = user_id

    async def process_frame(self, frame, direction):
        if isinstance(frame, TranscriptionFrame):
            # Flush finalized user transcripts into memory
            self.client.memories.create(content=frame.text, user_id=self.user_id)
        await self.push_frame(frame, direction)
Integrations / Voice & Real-Time / ElevenLabs

ElevenLabs Integration

Inject persistent bitemporal memories and customer personas directly into ElevenLabs Conversational AI voice agents.

Dynamic Prompt Context Injection

import requests
from piyapi import PiyAPIClient

piyapi = PiyAPIClient(api_key="sk_live_your_key_here")

def start_elevenlabs_conversation(agent_id: str, user_id: str):
    # 1. Fetch relevant persistent memory
    user_facts = piyapi.memories.search(query="caller preferences", user_id=user_id, limit=3)
    context_str = "; ".join([f["content"] for f in user_facts])

    # 2. Get signed WebSocket URL with dynamic variables
    res = requests.post(
        f"https://api.elevenlabs.io/v1/convai/conversation/get_signed_url?agent_id={agent_id}",
        headers={"xi-api-key": "your_elevenlabs_key"},
        json={"dynamic_variables": {"user_context": context_str}}
    )
    return res.json()["signed_url"]

BYOK KMS Envelope Encryption (User Guide §4.12)

PiyAPI supports customer-managed encryption keys (CMEK) via AWS KMS, Azure Key Vault, and Google Cloud KMS. All AES-256-GCM data encryption keys (DEKs) are wrapped with your master Key Encryption Key (KEK) before writing to persistent PostgreSQL storage.
