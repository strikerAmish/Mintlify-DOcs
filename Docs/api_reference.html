API Reference Overview

REST APIs for memory management, search, entity operations, and persistent context.

The PiyAPI REST API provides programmatic access to persistent memory and context operations, allowing applications and agents to create, retrieve, search, update, and manage memory through standard HTTP requests.

Authentication

All requests to the PiyAPI API must include a valid API key passed via the Authorization header using the Bearer scheme. Requests without a valid key will be rejected.

Header 
Authorization: Bearer <PIYAPI_API_KEY>
  • API keys should be stored server-side
  • Requests should be made through secure server-side environments
  • Do not expose secrets in client-side code
JavaScript 
const response = await fetch(
  "https://<your-negentro-api>/v1/memories",
  { headers: { Authorization: `Bearer ${process.env.PIYAPI_API_KEY}` } }
)

API Reference / Core Memory / Add Memories
POST /v1/memories

Add Memories

Create one or more persistent episodic memories with automated Active Inference surprise gating and PHI redaction.

Request Headers

HeaderTypeDescription
AuthorizationstringBearer <PIYAPI_API_KEY>
X-Workspace-IDstringOptional partition key isolating memory namespaces.

Request Body Parameters

FieldTypeRequiredDescription
user_idstringRequiredUnique identity anchor for the user, agent, or tenant.
messagesarray[object]RequiredList of dialogue messages (role: user/assistant, content: text).
scopestringOptionalIsolation level: 'user', 'session', 'agent', or 'global' (default: 'user').
metadataobjectOptionalArbitrary JSON key-value pairs indexed for scalar filtering.

Code Examples

integration.py 
from piyapi import PiyMemoryClient

client = PiyMemoryClient()
res = client.memories.add(
    user_id="usr_01J8K9",
    messages=[{"role": "user", "content": "Customer prefers quarterly invoicing over Stripe."}],
    metadata={"department": "finance", "tier": "enterprise"}
)
print(f"Memory stored: {res.events[0].id}, surprise: {res.surprise_score}")
integration.ts 
import { PiyMemoryClient } from "@piyapi/sdk";

const client = new PiyMemoryClient();
const res = await client.memories.add({
  userId: "usr_01J8K9",
  messages: [{ role: "user", content: "Customer prefers quarterly invoicing over Stripe." }],
  metadata: { department: "finance", tier: "enterprise" }
});
console.log(`Stored memory: ${res.events[0].id}`);
terminal.sh 
curl -X POST "https://api.piyapi.cloud/v1/memories" \
  -H "Authorization: Bearer $PIYAPI_API_KEY" \
  -H "Content-Type: application/json" \
  -d '{
    "user_id": "usr_01J8K9",
    "messages": [{"role": "user", "content": "Customer prefers quarterly invoicing over Stripe."}],
    "metadata": {"department": "finance"}
  }'

Response 201 Created

API Reference / Core Memory / Get Memories
GET /v1/memories

Get Memories

Retrieve a paginated list of persistent memories filtered by user, session, or time window.

Query Parameters

ParameterTypeRequiredDescription
user_idstringRequiredTarget user identifier.
limitintegerOptionalMax items returned (default 20, max 100).
scopestringOptionalFilter by scope ('user', 'session', 'agent', 'global').

Code Examples

integration.py 
from piyapi import PiyMemoryClient

client = PiyMemoryClient()
memories = client.memories.list(user_id="usr_01J8K9", limit=10)
for m in memories.items:
    print(f"[{m.id}] {m.content}")
integration.ts 
import { PiyMemoryClient } from "@piyapi/sdk";

const client = new PiyMemoryClient();
const res = await client.memories.list({ userId: "usr_01J8K9", limit: 10 });
res.items.forEach(m => console.log(m.content));
terminal.sh 
curl -X GET "https://api.piyapi.cloud/v1/memories?user_id=usr_01J8K9&limit=10" \
  -H "Authorization: Bearer $PIYAPI_API_KEY"

API Reference / Core Memory / Search Memories
POST /v1/memories/search

Search Memories

Execute 6-strategy hybrid search combining vector embeddings, BM25 exact match, graph walk distance, and recency decay.

Request Body Parameters

FieldTypeRequiredDescription
user_idstringRequiredUser or workspace identifier.
querystringRequiredNatural language search query.
limitintegerOptionalMaximum ranked results (default 5).
min_confidencefloatOptionalMinimum Bayesian belief score (0.0 to 1.0, default 0.75).

Code Examples

integration.py 
from piyapi import PiyMemoryClient

client = PiyMemoryClient()
res = client.memories.search(
    user_id="usr_01J8K9",
    query="invoicing and payment methods",
    limit=3,
    min_confidence=0.85
)
for r in res.results:
    print(f"[{r.score:.3f}] {r.content}")
integration.ts 
import { PiyMemoryClient } from "@piyapi/sdk";

const client = new PiyMemoryClient();
const res = await client.memories.search({
  userId: "usr_01J8K9",
  query: "invoicing and payment methods",
  limit: 3
});
res.results.forEach(r => console.log(`[${r.score}] ${r.content}`));
terminal.sh 
curl -X POST "https://api.piyapi.cloud/v1/memories/search" \
  -H "Authorization: Bearer $PIYAPI_API_KEY" \
  -H "Content-Type: application/json" \
  -d '{"user_id":"usr_01J8K9","query":"invoicing preferences","limit":3}'

PATCH /v1/memories/{memory_id}

Update Memory

Revise an existing memory belief non-destructively, preserving historical version lineage in PiyGraph.

Code Examples

integration.py

client = PiyMemoryClient()
updated = client.memories.update(
    memory_id="mem_01J8K9P2X",
    content="Customer switched to semi-annual invoicing via ACH.",
    metadata={"status": "revised"}
)
print("Updated belief. New version:", updated.version)
integration.ts 
import { PiyMemoryClient } from "@piyapi/sdk";

const client = new PiyMemoryClient();
const res = await client.memories.update({
  memoryId: "mem_01J8K9P2X",
  content: "Customer switched to semi-annual invoicing via ACH."
});
console.log(`Updated version: ${res.version}`);
terminal.sh 
curl -X PATCH "https://api.piyapi.cloud/v1/memories/mem_01J8K9P2X" \
  -H "Authorization: Bearer $PIYAPI_API_KEY" \
  -H "Content-Type: application/json" \
  -d '{"content":"Customer switched to semi-annual invoicing via ACH."}'

Submit Memory Feedback

Train adaptive decay and reinforce high-utility memory edges with user approval signals.
