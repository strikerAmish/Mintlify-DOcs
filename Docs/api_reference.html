API Reference Overview

REST APIs for memory management, search, entity operations, and persistent context.

The Negentro REST API provides programmatic access to persistent memory and context operations, allowing applications and agents to create, retrieve, search, update, and manage memory through standard HTTP requests.

Authentication

All requests to the Negentro API must include a valid API key passed via the Authorization header using the Bearer scheme. Requests without a valid key will be rejected.

Header 
Authorization: Bearer <NEGENTRO_API_KEY>
  • API keys should be stored server-side
  • Requests should be made through secure server-side environments
  • Do not expose secrets in client-side code
JavaScript 
const response = await fetch(
  "https://<your-negentro-api>/v1/memories",
  { headers: { Authorization: `Bearer ${process.env.NEGENTRO_API_KEY}` } }
)

API Reference / Core Memory Operations / Add Memories

Add Memories

Store new information, agent interactions, and bitemporal facts into persistent memory.

POST /api/v1/memories LIVE VERIFIED 
curl -X POST https://api.piyapi.cloud/api/v1/memories \
  -H "Authorization: Bearer $PIYAPI_API_KEY" \
  -H "Content-Type: application/json" \
  -d '{
    "content": "Client requested SOC2 Type II compliance audit report for Q3 2026.",
    "tags": ["compliance", "soc2", "audit"],
    "metadata": { "client_id": "cli_8812", "urgency": "high" },
    "valid_at": "2026-08-01T00:00:00.000Z"
  }'

Response Schema (201 Created):

{
  "memory": {
    "id": "8a1b2c3d-4e5f-6a7b-8c9d-0e1f2a3b4c5d",
    "content": "Client requested SOC2 Type II compliance audit report for Q3 2026.",
    "namespace": "default",
    "tags": ["compliance", "soc2", "audit"],
    "created_at": "2026-08-03T15:10:00.000Z"
  }
}
API Reference / Core Memory Operations / Get Memories

Get Memories

List stored memories scoped to your user or project with tag and date range filtering.

GET /api/v1/memories 
curl -X GET "https://api.piyapi.cloud/api/v1/memories?limit=10&tags=compliance" \
  -H "Authorization: Bearer $PIYAPI_API_KEY"
API Reference / Core Memory Operations / Search Memories

Search Memories

Execute multi-signal hybrid search fusing pgvector HNSW dense vectors and BM25 trigram full-text scores.

POST /api/v1/search 
curl -X POST https://api.piyapi.cloud/api/v1/search \
  -H "Authorization: Bearer $PIYAPI_API_KEY" \
  -H "Content-Type: application/json" \
  -d '{
    "query": "SOC2 audit report requests",
    "limit": 5,
    "alpha": 0.7,
    "tags": ["compliance"],
    "min_score": 0.25
  }'
API Reference / Core Memory Operations / Update Memory

Update Memory

Modify content, tags, or bitemporal validity of an existing memory record, generating a new revision version.

PATCH /api/v1/memories/:id 
curl -X PATCH https://api.piyapi.cloud/api/v1/memories/8a1b2c3d-4e5f-6a7b-8c9d-0e1f2a3b4c5d \
  -H "Authorization: Bearer $PIYAPI_API_KEY" \
  -H "Content-Type: application/json" \
  -d '{
    "content": "Updated compliance audit report status: Approved.",
    "tags": ["compliance", "soc2", "approved"]
  }'

Bulk Update Memories

Bulk append or replace tags and metadata across multiple memory records in a single transactional operation.

POST /api/v1/bulk/memories/tag 
curl -X POST https://api.piyapi.cloud/api/v1/bulk/memories/tag \
  -H "Authorization: Bearer $PIYAPI_API_KEY" \
  -H "Content-Type: application/json" \
  -d '{ "memory_ids": ["uuid-1...", "uuid-2..."], "add_tags": ["reviewed", "soc2"] }'

API Reference / Memory Management / Create Memory Export

Create Memory Export

Initiate asynchronous GDPR Article 15 (Right of Access) compliance export archives for a user dataset.

POST /api/v1/compliance/export GDPR COMPLIANT 
curl -X POST https://api.piyapi.cloud/api/v1/compliance/export \
  -H "Authorization: Bearer $PIYAPI_API_KEY"   -H "Content-Type: application/json"   -d '{
    "user_id": "usr_9921",
    "format": "json",
    "include_metadata": true
  }'

Response Schema (202 Accepted):

{
  "export_id": "exp_7f8a9b1c2d",
  "user_id": "usr_9921",
  "status": "pending",
  "estimated_completion_sec": 15
}
API Reference / Memory Management / Get Memory Export

Get Memory Export

Poll the status of an ongoing export job and obtain secure download links for generated archives.

GET /api/v1/compliance/export/:export_id 
curl -X GET https://api.piyapi.cloud/api/v1/compliance/export/exp_7f8a9b1c2d \
  -H "Authorization: Bearer $PIYAPI_API_KEY"

Response Schema (200 OK):

{
  "export_id": "exp_7f8a9b1c2d",
  "status": "completed",
  "download_url": "https://exports.piyapi.cloud/archives/usr_9921_export_2026.zip?token=...",
  "records_exported": 142,
  "expires_at": "2026-08-16T12:00:00.000Z"
}
API Reference / Events / Get Events

Get Events

Retrieve chronological audit events for memory creations, updates, connector syncs, and webhook executions.

GET /api/v1/events 
curl -X GET "https://api.piyapi.cloud/api/v1/events?limit=5&type=memory.created" \
  -H "Authorization: Bearer $PIYAPI_API_KEY"

Response Schema (200 OK):

{
  "events": [
    {
      "id": "evt_8192038",
      "type": "memory.created",
      "timestamp": "2026-08-15T10:14:22.100Z",
      "actor_id": "usr_9921",
      "payload": {
        "memory_id": "8a1b2c3d-4e5f-6a7b-8c9d-0e1f2a3b4c5d",
        "namespace": "default"
      }
    }
  ]
}
