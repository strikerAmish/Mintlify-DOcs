Start Here: 3 Fast-Track Paths to Production Memory

Deploy persistent, adaptive cognitive state across your agent infrastructure in under five minutes. Grounded in PiyAPI Master Architecture Blueprint §1.1 – §2.3.

•
Three Optimized Pathways: Depending on your target architecture, select between: (1) Quickstart Interactive Companion for immediate multi-turn conversational recall, (2) Enterprise Document & CDC Ingestion for streaming organization knowledge, or (3) Autonomous Agent Swarm with shared episodic memory pools.

Architecture Pipeline

[User Prompt / Agent Action] │ ▼ [Active Inference Engine] ──> Variational Surprise Scoring (Friston FEP: Δ ≤ 0.05) │ ├──> [L1 Working Memory: Redis/In-Memory Cache (<2ms)] ├──> [L2 Episodic Memory: Vector Search + HybridScorer (<15ms)] ├──> [L3 Semantic Memory: PiyGraph Bitemporal KG (valid_time vs tx_time)] └──> [L4 Procedural Memory: Tool Rules, Skills & Pinned Constraints]

Choose your runtime and configure your enterprise API credentials from the PiyAPI Cloud Console.

Memory Essentials: 4 Foundational Pillars

The architectural principles of modern cognitive systems: 4-Tier Memory Substrate, 8 Unified Operators, Active Inference, and Sovereign Unlearning.

01

Four-Tier Memory Substrate

Unlike traditional naive vector databases that store flat embeddings, PiyAPI orchestrates memory across 4 cognitive layers: L1 Working Memory (ephemeral in-flight prompt buffers, <2ms), L2 Episodic Memory (timestamped experiential logs with vector indices, <15ms), L3 Semantic Memory (PiyGraph bitemporal knowledge graph with dual-clock chronology: valid_time vs transaction_time), and L4 Procedural Memory (executable tool schemas, agent policies, and pinned user rules).

02

Eight Unified Memory Operators

Memory systems must perform more than just insert and retrieve. PiyAPI provides 8 atomic operators: store (ingest with surprise gating), retrieve (multi-strategy hybrid scoring), update (Bayesian prior revision without destructive overwrite), delete (cascade edge revocation), merge (entity deduplication across sessions), summarize (hierarchical graph abstraction), pin (immutable instruction anchoring), and verify (hallucination and consistency auditing).

03

Active Inference & Friston Free Energy (FEP)

Every incoming token stream is evaluated for Variational Surprise. Observations matching existing beliefs reinforce confidence; divergent facts create surprise. If surprise exceeds the threshold (Δ > 0.05), the fact is queued for Sleep Consolidation where Bayesian belief updating reorganizes graph edges without hallucinations.

04

Sovereign Graph Unlearn Engine (GDPR Art 17)

Compliance requires cryptographic certifiability. When a user requests data deletion, the Sovereign Unlearn Engine severs node references, zeros out vector embeddings, invalidates cryptographic keys in the token vault, and recalculates graph centrality with an automated cryptographic audit receipt.

Running the 8 Operators in Code

main.py 
from piyapi import PiyMemoryClient

client = PiyMemoryClient()

# 1. STORE with surprise gating
mem = client.memories.store(user_id="alice", content="Prefers TypeScript with strict null checks.")

# 2. RETRIEVE via 6-strategy HybridScorer
results = client.memories.retrieve(user_id="alice", query="coding style")

# 3. UPDATE belief
client.memories.update(memory_id=mem.id, new_content="Prefers TypeScript with strict mode and ESLint.")

# 4. PIN immutable prompt rule
client.memories.pin(user_id="alice", rule="Never generate any 'any' type in TypeScript code.")

# 5. VERIFY consistency against graph
audit = client.memories.verify(user_id="alice", claim="Does user allow any types?")
print("Belief verification:", audit.is_consistent, audit.confidence)

Build a Companion with PiyAPI (Negentro Engine)

Create a personal companion agent that tracks user tone, habits, emotional trajectory, and relationship history over months of conversation.

•
Cognitive Resonance: Standard LLM chatbots forget everything when the window clears. The Negentro engine continuously extracts conversational entities into PiyGraph, running a 6-phase biological sleep consolidation cycle every 24 hours to reinforce recurring relationship patterns.

Complete Companion Implementation

main.py 
import os
from piyapi import PiyMemoryClient
from openai import OpenAI

piy_client = PiyMemoryClient(api_key=os.environ["PIYAPI_API_KEY"])
llm = OpenAI(api_key=os.environ["OPENAI_API_KEY"])

USER_ID = "alex_san_francisco"

def companion_turn(user_message: str) -> str:
    # 1. Recall historical memories & persona state
    memories = piy_client.memories.search(
        user_id=USER_ID,
        query=user_message,
        limit=5,
        scope="user"
    )
    
    context_str = "\n".join([f"- {m.content}" for m in memories.results])
    
    # 2. Inject context into companion prompt
    system_prompt = f"""You are Samantha, an empathetic, intellectually curious companion.
You recall shared memories and respect the user's personality quirks.
Current Long-Term Memories:
{context_str}
"""
    
    response = llm.chat.completions.create(
        model="gpt-4o",
        messages=[
            {"role": "system", "content": system_prompt},
            {"role": "user", "content": user_message}
        ]
    )
    bot_reply = response.choices[0].message.content
    
    # 3. Asynchronously store the turn for Active Inference belief updating
    piy_client.memories.add(
        user_id=USER_ID,
        messages=[
            {"role": "user", "content": user_message},
            {"role": "assistant", "content": bot_reply}
        ]
    )
    return bot_reply

# Example usage:
print(companion_turn("I had another terrible meeting with the investor today."))
index.ts 
import { PiyMemoryClient } from '@piyapi/sdk';
import OpenAI from 'openai';

const piy = new PiyMemoryClient({ apiKey: process.env.PIYAPI_API_KEY! });
const openai = new OpenAI();
const USER_ID = 'alex_san_francisco';

export async function companionTurn(userMessage: string): Promise {
  const memories = await piy.memories.search({
    userId: USER_ID,
    query: userMessage,
    limit: 5,
    scope: 'user'
  });

  const contextStr = memories.results.map(m => `- ${m.content}`).join('\n');

  const completion = await openai.chat.completions.create({
    model: 'gpt-4o',
    messages: [
      { role: 'system', content: `You are Samantha, an empathetic companion.\nRecalled Memories:\n${contextStr}` },
      { role: 'user', content: userMessage }
    ]
  });

  const reply = completion.choices[0].message.content || '';

  // Ingest into memory substrate
  await piy.memories.add({
    userId: USER_ID,
    messages: [
      { role: 'user', content: userMessage },
      { role: 'assistant', content: reply }
    ]
  });

  return reply;
}

Interactive Memory Demo & REPL Playground

Inspect real-time memory formation, surprise scores, and belief updates in a terminal-based live REPL loop.

Interactive Terminal Script

main.py 
import os, sys
from piyapi import PiyMemoryClient

client = PiyMemoryClient(api_key=os.environ.get("PIYAPI_API_KEY"))
user_id = "demo_tester"

print("=== PiyAPI Interactive Memory REPL ===")
print("Commands: /search , /pin , /wipe, /exit")

while True:
    try:
        user_input = input("\nYou > ").strip()
        if not user_input: continue
        if user_input == "/exit": break
        
        if user_input.startswith("/search "):
            q = user_input[8:]
            res = client.memories.search(user_id=user_id, query=q)
            print(f"\nFound {len(res.results)} recalled memories:")
            for m in res.results:
                print(f"  * {m.content} (score: {m.confidence:.2f})")
            continue

        if user_input.startswith("/pin "):
            rule = user_input[5:]
            client.memories.pin(user_id=user_id, rule=rule)
            print(f"\n[PINNED RULE] {rule}")
            continue

        if user_input == "/wipe":
            client.memories.delete_all(user_id=user_id)
            print("\n[WIPED] All memories cleared for demo_tester.")
            continue

        # Normal dialogue turn
        res = client.memories.add(
            user_id=user_id,
            messages=[{"role": "user", "content": user_input}]
        )
        print(f"→ Ingested. Surprise Score: {res.surprise_score:.4f} | Events: {len(res.events)}")

    except (KeyboardInterrupt, EOFError):
        break

import readline from 'readline';
import { PiyMemoryClient } from '@piyapi/sdk';

const client = new PiyMemoryClient();
const userId = 'demo_tester';
const rl = readline.createInterface({ input: process.stdin, output: process.stdout });

console.log('=== PiyAPI Interactive TypeScript REPL ===');
rl.setPrompt('You > ');
rl.prompt();

rl.on('line', async (line) => {
  const text = line.trim();
  if (text.startsWith('/search ')) {
    const res = await client.memories.search({ userId, query: text.slice(8) });
    console.log(`Found ${res.results.length} memories:`, res.results.map(r => r.content));
  } else {
    const res = await client.memories.add({ userId, messages: [{ role: 'user', content: text }] });
    console.log(`Ingested. Surprise score: ${res.surprise_score}`);
  }
  rl.prompt();
});

from piyapi import PiyMemoryClient

        user_id=student_id,

weaknesses = client.memories.search(

    query="Which mathematics concepts need review or were failed?",
    limit=5
)

from piyapi import PiyMemoryClient

client = PiyMemoryClient()

def on_mastra_step_finish(step_id: str, agent_id: str, prompt: str, completion: str):
    client.memories.add(
        user_id=agent_id,
        scope="agent",
        messages=[

            {"role": "assistant", "content": completion}

Deploy Anthropic Claude 3.5 Sonnet and Amazon Titan embeddings on AWS Bedrock, backed by PiyAPI memory with IAM role authentication.

AWS Bedrock Integration Code

main.py 
import boto3, json
from piyapi import PiyMemoryClient

bedrock = boto3.client("bedrock-runtime", region_name="us-east-1")
piy = PiyMemoryClient()

user_id = "user_enterprise_aws_101"

# 1. Recall prior conversation context from PiyAPI
context = piy.memories.search(user_id=user_id, query="AWS infrastructure guidelines")
mem_context = "\n".join([f"- {m.content}" for m in context.results])

# 2. Invoke Claude 3.5 on Bedrock
body = json.dumps({
    "anthropic_version": "bedrock-2023-05-31",
    "max_tokens": 1000,
    "system": f"You are a DevOps Architect. Relevant context:\n{mem_context}",
    "messages": [{"role": "user", "content": "Deploy VPC peering to the analytics cluster."}]
})

res = bedrock.invoke_model(
    modelId="anthropic.claude-3-5-sonnet-20240620-v1:0",
    body=body
)
response_body = json.loads(res["body"].read())
print(response_body["content"][0]["text"])

Construct autonomous ReAct loops equipped with all 8 atomic operators: store, retrieve, update, delete, merge, summarize, pin, and verify.

Autonomous Memory Agent Loop

main.py 
from piyapi import PiyMemoryClient

client = PiyMemoryClient()
agent_id = "agent_orchestrator_01"

def agent_execution_step(goal: str):
    # 1. RETRIEVE pinned procedural constraints & episodic history
    pinned_rules = client.memories.get_pinned(user_id=agent_id)
    relevant_memories = client.memories.retrieve(user_id=agent_id, query=goal)
    
    # 2. Plan action considering recalled past failures
    print(f"Goal: {goal}")
    print(f"Loaded {len(pinned_rules)} rules and {len(relevant_memories.results)} memories.")
    
    # 3. VERIFY action against beliefs
    audit = client.memories.verify(user_id=agent_id, claim=f"Is action for '{goal}' safe?")
    if not audit.is_consistent:
        print("Safety violation detected in memory graph!")
        return
        
    # 4. STORE successful action outcome
    client.memories.store(
        user_id=agent_id,
        content=f"Successfully executed task for: {goal}"
    )

agent_execution_step("Provision secure S3 bucket with KMS encryption")

main.py 
from piyapi import PiyMemoryClient

client = PiyMemoryClient()
swarm_id = "swarm_research_alpha"

# Agent 1 (Scraper Agent): Writes to private scratchpad
client.memories.add(
    user_id="agent_scraper",
    scope="session",  # Private to this worker's turn
    messages=[{"role": "assistant", "content": "Parsed 14 candidate papers on quantum dot solar cells."}]
)

# Agent 2 (Evaluator Agent): Validates and commits to global blackboard
client.memories.add(
    user_id=swarm_id,
    scope="global",  # Accessible to all agents in swarm
    messages=[{"role": "assistant", "content": "Validated quantum efficiency metric: 24.8% confirmed by 3 independent labs."}],
    metadata={"verified_by": "agent_evaluator"}
)

# Lead Agent: Reads global blackboard
consensus = client.memories.search(
    user_id=swarm_id,
    scope="global",
    query="quantum dot solar cell efficiency",
    limit=5
)
for c in consensus.results:
    print(f"Swarm Consensus: {c.content}")

Ensure agent personality, voice characteristics, ethical guardrails, and compliance boundaries remain immutable over millions of dialogue tokens.

Immutable Persona Pinning & Drift Detection

main.py 
from piyapi import PiyMemoryClient

client = PiyMemoryClient()
agent_id = "agent_wealth_advisor_04"

# 1. Pin immutable ethical & compliance boundaries
client.memories.pin(
    user_id=agent_id,
    rule="""COMPLIANCE RULE: You are a registered financial advice bot. 
Never promise guaranteed returns on equities or crypto assets. 
Always include SEC standard disclaimers when discussing projections."""
)

# 2. Pin persona voice traits
client.memories.pin(
    user_id=agent_id,
    rule="""VOICE: Calm, conservative, analytical, objective. Use data-driven explanations."""
)

# 3. Verify outgoing statement against pinned boundaries
verification = client.memories.verify(
    user_id=agent_id,
    claim="This tech stock is guaranteed to double in 6 months."
)

if not verification.is_consistent:
    print("BLOCKED BY PERSONA GUARDIAN: Statement violates compliance rule.")
    print(f"Conflicting rule: {verification.conflicting_rule}")
