Start Here: 3 Fast-Track Paths to Production Memory

Deploying persistent memory takes under five minutes with PiyAPI REST endpoints or language SDKs.

Path 1: Store & Recall Memory in 2 Steps

Initialize your client with your live API key, store unstructured conversation facts, and perform multi-signal hybrid recall (dense vector + BM25 trigram fused with RRF_K=30).

TypeScript / Node.js — Minimal Companion Loop 
import { PiyAPIClient } from '@piyapi/sdk';

const client = new PiyAPIClient({
  apiKey: process.env.PIYAPI_API_KEY || 'sk_live_prod_key_here',
});

// 1. Ingest user interaction fact
const memory = await client.memories.create({
  content: 'User prefers dark mode UI and works primarily with React and TypeScript.',
  tags: ['preferences', 'tech-stack'],
  metadata: { source: 'onboarding_chat', user_id: 'usr_9918' }
});

// 2. Perform hybrid search during subsequent chat turns
const relevant = await client.search.query({
  query: 'What frontend framework does the user prefer?',
  limit: 5,
  include_metadata: true
});

console.log('Recalled memory:', relevant.results[0].content);

Path 2: Strict Multi-Tenant Namespace Isolation

For SaaS applications with multi-tenant architectures, pass the X-Namespace-Prefix header on every request to guarantee zero scope leakage across client organizations.

cURL — Namespace Scoping 
curl -X POST https://api.piyapi.cloud/api/v1/memories \
  -H "Authorization: Bearer YOUR API KEY" \
  -H "X-Namespace-Prefix: tenant_acme_corp" \
  -H "Content-Type: application/json" \
  -d '{
    "content": "Enterprise security policy mandates 90-day key rotations.",
    "tags": ["security", "policy"]
  }'

Path 3: Local Ollama & Air-Gapped Fallback

When running in privacy-sensitive or edge environments, use the BYOK routing engine or run local containers with pgvector and Ollama embeddings.

Build a Companion with Negentro & PiyAPI

Step-by-step guide to giving an AI assistant persistent long-term memory across sessions.

System Architecture

A persistent AI companion requires three synchronized subsystems: (1) Fact Extraction from user conversations, (2) Hybrid Vector + BM25 Storage with bitemporal timestamps, and (3) Context Window Injection during generation.

Python — End-to-End Companion Loop 
from piyapi_memory import PiyAPIClient

client = PiyAPIClient(api_key="YOUR API KEY")

def chat_turn(user_id: str, prompt: str) -> str:
    # Step 1: Recall relevant facts using hybrid RRF scoring
    context_records = client.search.query(
        query=prompt,
        filter={"metadata.user_id": user_id},
        limit=4
    )
    
    # Step 2: Format context injection
    memory_context = "\n".join([f"- {r['content']}" for r in context_records['results']])
    
    # Step 3: Run LLM inference with augmented context
    system_prompt = f"""You are a helpful personal companion.
User Background & Memories:
{memory_context}"""
    
    # Step 4: After replying, mine new facts for persistence
    client.memories.create(
        content=prompt,
        tags=["conversation"],
        metadata={"user_id": user_id}
    )
    return "Response generated with active context."

Research Assistant for YouTube

Ingest YouTube video transcripts, timestamps, and chapters into hybrid search.

Transcript Ingestion Pipeline

Extract transcripts from YouTube and index each chapter with timestamp metadata:

Python — YouTube Ingestion 
from youtube_transcript_api import YouTubeTranscriptApi
from piyapi_memory import PiyAPIClient

client = PiyAPIClient(api_key="sk_live_prod_key_here")

def index_youtube_video(video_id: str, title: str):
    transcript = YouTubeTranscriptApi.get_transcript(video_id)
    full_text = " ".join([t['text'] for t in transcript[:20]])
    
    client.memories.create(

        tags=["youtube", "research-transcript"],
        metadata={"video_id": video_id, "title": title}
    )
    print("Video indexed successfully.")

Cookbooks/Integrations/AWS Bedrock
Cloud AI AWS Bedrock Active

AWS Bedrock with Persistent Memory

Combine AWS Bedrock foundation models with PiyAPI hybrid search and pgvector memory stores.

Converse API & Context Retrieval

Python — Bedrock Converse Loop 
import boto3
from piyapi_memory import PiyAPIClient

bedrock = boto3.client('bedrock-runtime', region_name='us-east-1')
piyapi = PiyAPIClient(api_key="sk_live_prod_key_here")

def generate_with_bedrock(user_id: str, prompt: str):
    # 1. Retrieve user memory
    mems = piyapi.memories.search(query=prompt, user_id=user_id, limit=3)
    context = "\n".join([m['content'] for m in mems])
    
    # 2. Invoke Bedrock Converse API
    response = bedrock.converse(
        modelId="anthropic.claude-3-5-sonnet-20240620-v1:0",
        messages=[{"role": "user", "content": [{"text": f"Context:\n{context}\n\nQuestion: {prompt}"}]}]
    )
    return response['output']['message']['content'][0]['text']
