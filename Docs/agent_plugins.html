Claude Code

Persistent cross-session memory for Claude Code.

Connect PiyAPI to your coding agent so relevant context can persist across sessions and become available when you need it.

✓
Current plugin version: v1.2.0

Prerequisites

01
PiyAPI account / API key — required to authenticate requests. Set it as PIYAPI_API_KEY ,
02
Supported agent environment — Claude Code CLI must be installed and accessible on your path.
03
Required runtime/CLI dependencies — Node.js 18+ and negentro-cli .

Quick start

export PIYAPI_API_KEY="your-api-key"
negentro plugin install claude-code
negentro plugin status

This installs the plugin, wires it into your Claude Code session, and confirms the connection is active.

Commands

Cursor Integration

Persistent repository memory and AST symbol recall for Cursor Agent and Composer.
•
Context Retention Moat: When refactoring multi-file features in Cursor Composer, traditional context windows truncate previous discussion. PiyAPI MCP maintains an external bitemporal index of your codebase, architectural decisions, and past bugfixes.

1. MCP Server Configuration (.cursor/mcp.json)

Add the PiyAPI MCP server to your project-specific or global Cursor MCP configuration:

.cursor/mcp.json 
{
  "mcpServers": {
    "piyapi-memory": {
      "command": "npx",
      "args": ["-y", "@piyapi/mcp-server"],
      "env": {
        "PIYAPI_API_KEY": "YOUR_PIYAPI_API_KEY",
        "PIYAPI_WORKSPACE_ID": "ws_cursor_repo_main",
        "PIYAPI_SURPRISE_THRESHOLD": "0.05"
      }
    }
  }
}

2. Available MCP Tools in Cursor

Once connected, Cursor Agent automatically gains access to these core tools:

Tool Name Parameters Description
recall_memory query, limit, scope Searches past bugfixes, architecture rules, and conventions.
store_memory content, metadata Persists newly discovered architectural decisions or resolved issues.
pin_rule rule, category Permanently anchors code style or security invariants.
kg_time_travel query, as_of_timestamp Queries repository memory as it existed at a past git commit.

3. Pinned Rules in .cursorrules

Add memory instructions to your .cursorrules file to enforce automatic memory recall before any major refactoring:

.cursorrules 
# PiyAPI Memory Directives for Cursor
1. Before modifying database models or API routes, invoke `recall_memory` with keywords from the prompt.
2. If an architectural decision is made (e.g., choice of library, schema change), invoke `store_memory`.
3. Never bypass pinned invariants recalled from `recall_memory`.

Agent Plugins / Agent Harnesses / LiveKit
Voice & Real-Time Sub-15ms Latency

LiveKit Real-Time Voice Agent Memory

Inject ultra-low latency conversational recall into real-time WebRTC audio agents.

1. Agent Lifecycle Hook

Integrate PiyAPI memory into the LiveKit Agents Python SDK worker:

livekit_worker.py 
from livekit.agents import JobContext, WorkerOptions, cli
from piyapi import PiyMemoryClient

piy = PiyMemoryClient()

async def entrypoint(ctx: JobContext):
    await ctx.connect()
    participant = await ctx.wait_for_participant()
    
    # 1. Warm memory cache (<15ms)
    recalled = piy.memories.retrieve(
        user_id=participant.identity,
        query="Recent support inquiries and caller preferences"
    )
    print(f"Preloaded {len(recalled.results)} facts for voice agent.")

if __name__ == "__main__":
    cli.run_app(WorkerOptions(entrypoint_fnc=entrypoint))

Agent Plugins / Plugin Resources / Troubleshooting
Diagnostics Error Matrix

Troubleshooting & Diagnostics

Diagnostic matrix and mitigation steps for common agent plugin issues.

1. Error & Symptom Diagnostic Matrix

Error / Symptom Root Cause Mitigation & Fix
401 Unauthorized Missing, revoked, or expired PIYAPI_API_KEY. Verify key in PiyAPI Cloud Console. Test via curl -H "Authorization: Bearer $KEY" https://api.piyapi.cloud/v1/health.
MCP stdio pipe hang Node.js subprocess crashed or stderr output corrupted json-rpc stream. Ensure Node.js 18+ is installed. Set DEBUG=false in mcp.json to prevent raw text logs on stdout.
Empty search results Overly narrow workspace filter or confidence cutoff too high. Lower min_confidence from 0.90 to 0.70. Verify workspace ID matches git root.
PHI false positives Variable names matching healthcare or PII patterns. Disable PHI check for coding workspaces via PIYAPI_REDACT_PHI=false.
Session flush failed Terminal closed abruptly before sleep consolidation ran. Run /memory:pin or trigger a manual sync before terminating terminal tabs.

2. Viewing Diagnostic Logs

Inspect plugin daemon activity logs directly via the CLI:

bash 
# View live plugin telemetry and surprise score events
piyapi logs --tail 50 --level debug
