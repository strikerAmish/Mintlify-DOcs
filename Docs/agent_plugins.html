Claude Code

Persistent cross-session memory for Claude Code.

Connect Negentro to your coding agent so relevant context can persist across sessions and become available when you need it.

✓
Current plugin version: v1.2.0

Prerequisites

01
Negentro account / API key — required to authenticate requests. Set it as NEGENTRO_API_KEY ,
02
Supported agent environment — Claude Code CLI must be installed and accessible on your path.
03
Required runtime/CLI dependencies — Node.js 18+ and negentro-cli .

Quick start

export NEGENTRO_API_KEY="your-api-key"
negentro plugin install claude-code
negentro plugin status

This installs the plugin, wires it into your Claude Code session, and confirms the connection is active.

What you can do

Automatic memory
Captures relevant context from coding sessions automatically, without manual intervention.
Commands
Explicit commands for searching, checking status, forgetting, and pausing/resuming memory capture.
Search tool
Search previous sessions and retrieve relevant context on demand.
Sidekick agent
Run isolated investigation or implementation work while preserving the primary context.

Commands

COMMAND WHAT IT DOES
/memory:search Search memories from earlier sessions.
/memory:status Check current memory/configuration state.
/memory:forget Delete or forget selected memories.
/memory:pause Pause automatic memory capture.
/memory:resume Resume automatic memory capture.
/memory:remember Explicitly capture something important.

Cursor

Persistent memory & Model Context Protocol (MCP) server for Cursor.

Integrate Negentro directly into Cursor using the standard stdio MCP transport to provide full access to 30 cognitive memory tools, semantic search, and context assembly.

✓
Current MCP server: @piyapi/mcp-server v1.0.4

MCP Server Configuration

Add the Negentro MCP server to your Cursor configuration file (.cursor/mcp.json or global Cursor settings):

{
  "mcpServers": {
    "negentro": {
      "command": "npx",
      "args": ["-y", "@piyapi/mcp-server"],
      "env": {
        "PIYAPI_API_KEY": "sk_live_your_api_key_here"
      }
    }
  }
}

Once connected, Cursor's AI composer and chat can invoke 30 specialized memory tools:

✓

Authentication & Webhook Token

Configure your OpenClaw agent runtime with a dedicated webhook ingest token from Section 7.2 of the Negentro platform:

{
  "connector": "open_claw",
  "purpose": "Web scrapers & RSS feeds",
  "auth_schema": {
    "webhook_ingest_token": "whsec_live_9a8b7c6d5e4f3a2b1c"
  }
}

Scraped pages are chunked, embedded with bitemporal valid-time timestamps, and evaluated with the UnifiedScorer for automatic recency decay and deduplication.

Agent Plugins / Plugin Resources / Overview

Plugin Overview

Architecture and capabilities of Negentro Agent Plugins.

Negentro Agent Plugins enable AI agents to maintain cross-session memory, access unified context assembly, and query previous interactions without polluting token windows.

Core Pillars

1. Bitemporal Graph Memory
Stores both valid time (when the fact was true in the real world) and transaction time (when the system recorded it), allowing precise version rollbacks.
2. UnifiedScorer Retrieval
Combines dense HNSW vector similarity, sparse BM25 text match, recency decay, and relation graphs for high-precision retrieval.
3. Model Context Protocol (MCP)
Standard stdio transport providing 30 native tools for Cursor, Windsurf, Claude Desktop, and CLI agents.

Agent Plugins / Plugin Resources / Memory

Memory Architecture

Bitemporal memory lifecycle and context scoping.

The 4-Step Lifecycle

01
Capture: Records agent conversation turns, edits, and tool results.
02
Flush: Dispatches payloads at interaction boundaries or idle triggers.
03
Extract: LLM extractor parses key technical decisions, constraints, and dependencies.
04
Recall: UnifiedScorer fetches context when new prompts are submitted.
