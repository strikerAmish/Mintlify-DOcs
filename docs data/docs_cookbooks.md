# Cookbooks & Tutorials

Build practical AI applications with ready-to-use examples, workflows, and integrations powered by PiyAPI.

> From first memory workflows to production-ready agent systems.

Cookbooks provide practical implementation examples for building with PiyAPI. Each guide demonstrates a reusable application pattern—from simple memory workflows to full agent systems—featuring working code, architectural constraints, and integration patterns adapted directly for production.

These examples are engineered to be copied, modified, and shipped.

* More personalized AI applications
* More reliable context retrieval
* Reduced unnecessary model interactions
* Reusable memory workflows
* Practical implementation patterns

## Companion Playbooks

Build assistants that retain user preferences, goals, and historic interaction states.

* **Interactive Memory Demo**: Execute persistent memory workflows inside a real application. `DEMO`
* **Research Assistant for YouTube**: Inject personalized context directly into video research and retrieval. `RESEARCH`
* **Voice-First AI Companion**: Build a voice-first experience leveraging persistent context. `VOICE`
* **Personalized AI Tutor**: Maintain deterministic student progress state across sessions. `EDUCATION`
* **Smart Travel Assistant**: Persist traveler preferences and planning context. `TRAVEL`
* **Build a Node.js Companion**: Create a strictly-typed JavaScript companion that retains user context. `SDK`

## Ops & Automations

Leverage persistent context to automate recurring workflows and multi-step tasks.

* **Automated Email Intelligence**: Parse and retain relevant unstructured information from email pipelines. `AUTOMATION`
* **Content Creation Workflow**: Persist tone, style, and content guidelines as reusable context parameters. `CONTENT`
* **Multi-Session Research Agent**: Execute asynchronous research workflows across sessions without context degradation. `RESEARCH`
* **Memory-Powered Support Agent**: Inject historic customer context directly into support agent flows. `SUPPORT`
* **Collaborative Task Assistant**: Coordinate multi-user workflows while maintaining strict context boundaries. `COLLABORATION`

## Integrations & Platforms

Use PiyAPI memory inside the platforms and environments that power your AI workflows.

* **Memory-Powered Agent SDK**: Expose callable memory tools for autonomous agent workflows. `SDK`
* **Memory as an API Tool**: Utilize persistent memory within strict function-calling environments. `API`
* **Persistent Mastra Agents**: Deploy persistent agents leveraging Mastra-based architectures. `FRAMEWORK`
* **Healthcare Context with ADK**: Maintain compliant, relevant context across isolated agent sessions. `HEALTHCARE`
* **Search with Personal Context**: Execute real-time search queries against persistent user profiles. `SEARCH`
* **Bedrock with Persistent Memory**: Integrate cloud AI infrastructure directly with PiyAPI memory stores. `CLOUD`

## Frameworks & Multimodal

Explore cookbooks that combine PiyAPI with agent frameworks and multimodal applications.
