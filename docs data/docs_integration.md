## 4. Hero Section

# Integrations Overview
Connect PiyAPI with the frameworks, agent platforms, developer tools, and infrastructure you already use.

PiyAPI integrates with the tools used to build modern AI applications, allowing persistent memory and context to become part of existing workflows.

* Persistent context across frameworks
* Consistent memory across AI interactions
* Context-aware agent workflows
* Framework-specific development patterns
* Simple integration through SDKs and APIs

### Benefits
* **Persistent memory** across supported frameworks
* **Context retrieval** inside existing agent workflows
* Consistent **user and session context**
* **Framework-agnostic** memory infrastructure
* Simple **SDK and API-based** integration

> **Universal integration**
> Use PiyAPI through a standardized API layer when your workflow does not require a framework-specific integration.

### Agent Frameworks

* **AgentOps**
  Monitor agent workflows while retaining relevant memory and context across interactions.
* **Camel AI**
  Connect persistent context to multi-agent workflows.
* **LangChain**
  Add persistent memory and context to LangChain-based applications using `packages/langchain-adapter`.
* **LlamaIndex**
  Connect persistent memory with retrieval and data workflows.
* **AutoGen**
  Build agent workflows that can retain context across interactions.
* **CrewAI**
  Give multi-agent workflows a shared, persistent context graph (PiyGraph).
* **LangGraph**
  Connect persistent memory to LangGraph workflows.
* **Dify**
  Add long-term context to applications built with Dify.
* **ChatDev**
  Add persistent context to collaborative AI workflows.
* **Agno**
  Connect persistent context to Agno-based workflows.

### AI SDKs

* **Vercel AI SDK**
  Use PiyAPI alongside the Vercel AI SDK.
* **PiyAPI SDK**
  Add bitemporal memory and context to native agent workflows using `@piyapi/sdk`.
* **Google ADK**
  Connect PiyAPI memory with Google agent development workflows.

### Voice & Real-Time

* **LiveKit**
  Connect persistent context to real-time voice workflows.
* **Pipecat**
  Build real-time agent workflows with memory.
* **ElevenLabs**
  Use persistent memory in conversational voice applications.

### Data Connectors (CDC Auto-Sync)

* **Notion**
  Continuous Change Data Capture for Workspace pages and databases.
* **Google Drive**
  Sync context directly from Docs, Sheets, and Slides.
* **GitHub**
  Extract context from Repositories, Issues, PRs, and Commits.
* **Slack**
  Ingest thread history and channel conversations.
* **Jira & Confluence**
  Track enterprise tickets and knowledge base articles.

### Developer Tools

* **LangChain Tools**
  Connect memory to tool-driven agent workflows.
* **Model Context Protocol (MCP)**
  Connect Cursor, Windsurf, and Claude Desktop to PiyAPI natively via `@piyapi/mcp-server`.
* **REST API**
  Direct programmatic access to bitemporal graphs and context retrieval.
* **Webhooks**
  Real-time HTTP POST callbacks for memory creation and connector sync events.

### Infrastructure

* **AWS Bedrock**
  Use PiyAPI alongside AWS model and agent infrastructure.
* **BYOK Managers**
  Route generation natively through OpenAI, Anthropic, Gemini, DeepSeek, Mistral, Groq, Cohere, and Perplexity.
* **PostgreSQL & pgvector**
  Enterprise-grade bitemporal storage substrate and dense vector indexes.
* **Redis**
  Ultra-low latency semantic caching layers.
