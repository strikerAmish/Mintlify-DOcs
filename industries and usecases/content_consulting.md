### Section 9: Frequently Asked Questions
* **Label:** `07 QUESTIONS`
* **Title:** Frequently asked.
* **FAQ 1:**
  * **Q:** How does a copilot know what decisions have already been made?
  * **A:** PiyApi remembers across threads. Each session's interactions are processed into memory scoped exclusively to that department, so the copilot knows what is resolved, what is pending, and what needs escalation.
* **FAQ 2:**
  * **Q:** How are different departments kept separate at scale?
  * **A:** Negentro enforces strict per-org memory isolation at the infrastructure level. Every department's context graph is structurally partitioned, ensuring zero data leakage, backed by privacy tokenization and real-world token economics.
* **FAQ 3:**
  * **Q:** Can it extract data from scattered Slack channels and Google Drive?
  * **A:** Yes. PiyApi syncs across 12 native CDC connectors to extract knowledge from unstructured enterprise data, mapping them semantically so consultants can ask questions across platforms.
* **FAQ 4:**
  * **Q:** What happens when an internal policy is updated or overridden?
  * **A:** PiyApi features Deterministic Conflict Resolution via its bitemporal graph. It structurally segregates when a fact becomes true from when it was ingested, overriding outdated context—recognizing a policy change—without injecting LLM hallucinations.
* **FAQ 5:**
  * **Q:** Does shared firm knowledge mix with an employee's private drafts?
  * **A:** No. Global knowledge (like company handbooks) is integrated seamlessly with personal memory, but private meeting notes never pollute the shared global knowledge base.
* **FAQ 6:**
  * **Q:** Is this a finished HR portal or something I build on?
  * **A:** PiyApi is the foundational memory API and infrastructure layer, delivering O(1) constant time latency. We provide the memory intelligence; you build the enterprise application, intranet, and copilot on top.
